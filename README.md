# Flow Tab - Chrome 新标签页扩展

一个简约美观的 Chrome / Chromium 新标签页扩展

![Preview](icons/image.png)



## 安装使用步骤

### 1. 打开 Chrome 扩展管理页
在 Chrome / Edge 地址栏输入：
```text
chrome://extensions
```
或 
```
edge://extensions
```

### 2. 开启开发者模式
在扩展管理页面右上角，开启 **“开发者模式” (Developer mode)** 开关。

### 3. 加载已解压的扩展程序
1. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
2. 在弹出的文件选择器中，选中本插件目录
3. 点击“选择文件夹”。

### 4. 体验全新标签页
在浏览器中按下 `Ctrl + T` 打开一个新标签页，即可看到完整页面
