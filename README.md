# Flow Tab - 极简高颜值 Chrome 新标签页扩展

基于现代流光视觉美学与轻量级无障碍交互打造的 Chrome / Chromium 新标签页扩展（Manifest V3）。

![Preview](icons/icon-128.png)

## ✨ 特色功能

1. **原汁原味视觉美学（1:1 复刻质感）**：
   - **柔和中心环境光晕**：温暖呼吸感渐变背景弥散层。
   - **品牌几何流光 Logo**：精致四瓣编织质感图标，伴随优雅悬浮微动效。
   - **全能浮动输入卡片**：圆角卡片、多层阴影、毛玻璃模糊滤镜。
2. **“输入 / 唤起妙招” 快捷指令系统**：
   - 随时键入 `/` 呼出妙招命令列表（`/google`、`/baidu`、`/bing`、`/deepseek`、`/chatgpt`、`/github`、`/bilibili`、`/bm`、`/hist`、`/calc`、`/trans`、`/note`、`/theme`）。
   - 全键盘友好：支持 `↑` / `↓` 切换、`Enter` 触发、`Esc` 退出。
3. **搜索引擎与 AI 模式即时切换**：
   - 点击底部 `@` 图标或右侧 `Default` 胶囊，快速在 Google、百度、必应、DeepSeek AI、ChatGPT、GitHub 之间快速切换。
4. **Bento 常用应用直达矩阵**：
   - 点击底部四方块 Bento 图标，一键展示常用效率站点捷径。
5. **左侧抽屉百宝箱**：
   - **书签快捷检索**：直接读取 Chrome 本地书签树，快速点击打开。
   - **浏览历史记录**：快速回溯最近访问过的网址。
   - **随时便签小记**：支持临时随手记，输入自动持久化同步。
6. **右下角外观个性化定制**：
   - 5 种光晕配色：晨曦暖橙、极光幽紫、翠微青竹、澄澈海蓝、霞彩玫瑰。
   - 暗黑深色模式一键切换。
   - 底部提示胶囊开关与默认搜索引擎配置。

## 🚀 安装使用步骤

### 1. 打开 Chrome 扩展管理页
在 Chrome / Edge 地址栏输入：
```text
chrome://extensions
```
或 `edge://extensions`。

### 2. 开启开发者模式
在扩展管理页面右上角，开启 **“开发者模式” (Developer mode)** 开关。

### 3. 加载已解压的扩展程序
1. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
2. 在弹出的文件选择器中，选中本插件目录：
   ```text
   C:\Users\33534.WANFENG.DESKTOP-CFDPLID\.gemini\antigravity\scratch\flow-newtab-extension
   ```
3. 点击“选择文件夹”。

### 4. 体验全新标签页
在浏览器中按下 `Ctrl + T` 打开一个新标签页，即可看到完整页面！
